## Протокол «добора» (следующий заезд, ~15 мин)
Логгер снимаю сам по COM7; доработка — в каждом цикле блок стандартных PID (7DF) + пере-`81` +
блок проприетарных (все 5 страниц, ОБЯЗАТЕЛЬНО с `ATAL`). Тогда есть синхронный эталон.
Действия по команде:
1. Холостой (база). 2. Газовка ~2500 держать. 3. **Кондиционер ВКЛ** ~1 мин (FanSpeed, AirCPress).
4. Нажать **тормоз** несколько раз (BR, BrakePress), **сцепление** (CL). 5. Поехать: разгоны,
ровная скорость, **накат/торможение двигателем** (CanisterValve, MixCorr, O2). 6. Переключения передач (Gear).
По синхронному эталону привязываются Speed, AccelPedalPos, IntakeAirPress/Instr, Load, Gear;
по off→on — FanSpeed/AirCPress; по осцилляции/накату — O2, коррекции смеси, адсорбер.

## Технические заметки (критично для воспроизведения)
- Последовательность CAN: `ATSP6; ATSH6A8; ATCRA688; ATFCSH6A8; ATFCSD300000; ATFCSM1; 81` → затем `21CB/21CA/21C0/21C1/21C2`.
- **`81` обязателен** перед проприетарными чтениями (и как keep-alive каждый цикл — иначе часть страниц уходит в NODATA).
- **`ATAL` обязателен** — без него ELM отдаёт только первый фрейм (многокадровые данные теряются).
- Многокадровый ответ ELM: строка длины (`03B`) + строки `0:`,`1:`… — парсер приложения (`cleanHex`) это снимает.
- Стандартные OBD-II PID (RPM, ОЖ, скорость, MAP, дроссель, УОЗ, нагрузка, лямбды B1S1/B1S2, напряжение, DTC) читаются functional-заголовком **7DF/7E8** и в Car Scanner уже встроены — их отдельно как custom PID делать не нужно.
