Настройки подключения

Для адаптеров, которые работают на iPhone по Bluetooth (Konnwei BLE и т.п.), выберите Bluetooth LE. Требует запуск через http://localhost (см. README).
Для Bluetooth-COM значение не важно. Для USB — как в вашем адаптере.
OBD-II стандарт — корректные значения сразу. CAN PSA — проприетарные FAP-параметры (смещения пока не откалиброваны). K-line — только для адаптера с рабочим K-line.
Сдвигает смещение всех параметров разом. Нужен только если значения выглядят неверно относительно живого дампа 21Cx.
