Настройки подключения

Для адаптеров, которые работают на iPhone по Bluetooth (Konnwei BLE и т.п.), выберите Bluetooth LE. Требует запуск через http://localhost (см. README).
Для Bluetooth-COM значение не важно. Для USB — как в вашем адаптере.
CAN PSA — 118 параметров ЭБУ по 10 страницам, плюс чтение ошибок и идентификация. Смещения, формулы, единицы и текстовые состояния взяты из официальных баз Diagbox (см. out/diagbox_v46_21_reference.md). OBD-II стандарт — обычные mode-01 PID. K-line — только для адаптера с рабочим K-line.
Сдвигает смещение всех параметров разом. Со смещениями из базы Diagbox не требуется — оставьте 0.
